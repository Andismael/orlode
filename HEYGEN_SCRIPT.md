## 🔄 Variantes selon ta cible

Le texte ci-dessus est générique restaurateur. Voici les ajustements selon ton prospect :

### Pour une coiffeuse / esthéticienne
- Remplace "restaurant" par "salon"
- Remplace "Royal Bordeaux" par "Pastel Beauté"
- Remplace "Chez Maman" par "Chez Malou"
- "Mes clientes prennent leurs RDV sur WhatsApp" au lieu de "réserver une table"
- Lien démo : `/agents/service`

### Pour un médecin / dentiste / avocat / notaire
- Remplace "restaurant" par "cabinet"
- Mentionne "confidentialité" et "agenda"
- "Mes patients prennent leurs rendez-vous"
- Lien démo : `/agents/cabinet`

### Pour un hôtel
- Remplace "restaurant" par "hôtel"
- "Mes voyageurs réservent leurs chambres"
- Mentionne "iCal Booking et Airbnb synchronisés"

### Pour une boutique
- Remplace "restaurant" par "boutique"
- "Vends sur WhatsApp avec une photo"
- Mentionne "POS" si vente physique aussi

### Version 60 secondes (plus courte, mêmes points)
Coupe :
- [0:15 — Solution intro] entièrement
- [1:12 — Bénéfice] et passe direct à [1:22 — Prix]

## 🎯 Après la production HeyGen

1. **Télécharger** la vidéo en MP4 1080p
2. **Recadrer si besoin** : version 9:16 (TikTok/Stories) + version 16:9 (LinkedIn) avec CapCut ou Premiere
3. **Ajouter** un overlay final "orlode.com" sur les 3 dernières secondes si HeyGen ne le fait pas
4. **Sous-titres burnés** : si tu vises l'Afrique de l'Ouest, brûle les sous-titres FR dans la vidéo (beaucoup regardent sans son)
5. **Tester** : envoie à 3 amis avant diffusion, demande "Tu comprends en combien de secondes ?"
6. **Diffuser** :
   - Status WhatsApp
   - Stories Instagram + Facebook
   - LinkedIn post
   - TikTok
   - Message direct à 20 prospects qualifiés
